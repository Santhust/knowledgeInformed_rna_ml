# Knowledge-Informed ML: When Better Structure Does Not Mean Better Prediction

A controlled synthetic study of how experimental, structural, and
biological-module priors affect prediction, interpretability, selective
prediction, and robustness.

> **This is a synthetic methodological study, not a real RNA-folding or
> FRET prediction system.** All data are generated by a documented simulator.
> FRET-like measurements are simulated, not measured. No biological or
> clinical validation is claimed, and predictive relevance is not causal
> evidence.

---

## Scientific question

**When does biological prior knowledge actually help a machine-learning
model?**

Knowledge is often available in the form of mechanistic understanding, a
pathway diagram, a structural constraint, or experimental expectation — and
passing it into a model does not automatically improve results. This project
examines what actually happens, in a setting where the hidden structure is
known by construction and can therefore be inspected directly.

Five questions are asked, each against a shared five-fold protocol:

1. Can a simple prototype classifier stay competitive with conventional
   baselines?
2. Do experimental, structural, and module-level priors improve prediction?
3. Can biological structure be represented more faithfully *without*
   improving discrimination?
4. Can prototype geometry identify difficult decisions and support
   abstention?
5. How do frozen models respond to degraded experimental evidence?

## Main findings

- **A regularized logistic baseline is already strong** in this synthetic,
  moderate-dimensional regime. Relevance weighting and gradient boosting do
  not beat it.
- **Prior knowledge is not automatically predictive, and its encoding
  matters.** An engineered experimental feature is approximately neutral; a
  structural prior gives a small positive change; an uncertainty-aware
  distance *reduces* AUROC — the largest single effect in the project, and a
  regression.
- **Correct biological module aggregation improves recovery of the intended
  latent structure without improving discrimination.** The correct grouping
  correlates best with its own latent module state in both modules, yet
  predictive AUROC does not improve, and a deliberately incorrect grouping
  performs similarly. These latent correlations are **diagnostic only** — they
  use ground truth that is never a model input.
- **Prototype margins identify harder decisions and support selective
  prediction.** Rejecting low-margin cases raises accuracy among accepted
  samples where matched random rejection does not. The margin is a difficulty
  signal, not calibrated probabilistic uncertainty.
- **Robustness experiments show that a model can appear to improve under
  corruption because a harmful modelling choice is being weakened.** The
  worst model is the one that improves under noise.

Effect sizes are small, no significance testing was performed on the model
comparisons, and every conclusion is conditional on the simulator.

## Reproducing the analysis

### Setup

Python 3.13 is used. From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Run the pipeline

The pipeline is a sequence of scripts, **not** a single command. Run them in
order from the repository root:

```bash
# 1. synthetic data (writes data/generated/ — gitignored)
python src/generate_data.py

# 2. experiments (each writes one JSON into results/)
python src/baseline.py                    # m0_baseline_metrics.json, m0_cross_validation.json
python src/prototype_model.py             # prototype_baseline_cv.json
python src/relevance_prototype.py         # relevance_prototype_cv.json
python src/fret_knowledge.py              # fret_knowledge_cv.json
python src/structural_knowledge.py        # structural_knowledge_cv.json
python src/network_knowledge.py           # network_knowledge_cv.json
python src/rejection.py                   # rejection_cv.json
python src/robustness.py                  # robustness_cv.json

# 3. latent module diagnostic (no model is fitted)
python src/persist_module_diagnostic.py   # module_latent_diagnostic.json

# 4. final figures — reads results/, fits nothing
python src/make_final_figures.py
```

Each step uses a fixed seed and the same five-fold partition
(`random_state=0`, fold fingerprint `9b587aa3d19a36f7`), which is asserted at
load time so results cannot silently drift apart.

The notebooks in `notebooks/` reproduce the same analyses with the full
working shown; they are the narrative record and are the right place to look
for evidence behind each number.

**Final figures do not refit anything.** `src/make_final_figures.py` reads the
persisted JSON files in `results/`, recomputes no metric, and fails loudly if a
source or key is missing. Its output is byte-identical across runs, and it
carries run-time checks on axis conventions, label placement, and legend
semantics.

`scipy` is listed in `requirements.txt` because `notebooks/08_rejection.ipynb`
uses it (`from scipy import stats`) for its Mann–Whitney check. No script in
`src/` depends on it, so the analysis pipeline above does not require it — it is
needed to run that notebook.

## Scope and limitations

- The dataset is **synthetic**; FRET-like measurements are simulated.
- This is **not** real RNA folding and **not** real RNA 3D-structure
  prediction.
- The pathway/network component is a small synthetic hierarchy, not curated
  biology.
- Roughly 800 samples with a modest number of observed features.
- **No systematic sample-size analysis was run.** Logistic regression is hard
  to beat in this regime, which limits what small prior effects can be
  distinguished.
- No statistical significance tests for the small model differences; several
  effects are comparable to their own fold-level spread.
- Only FRET-like degradation was tested for robustness — structural and
  network corruption were not.
- No claim of superiority over deep learning or modern biological foundation
  models; none was compared against.

The full limitation list, and the open questions it implies — sample size and
sample efficiency, nonlinear problem complexity, imperfect priors, alternative
knowledge-integration mechanisms, multiple uncertainty sources, and
semi-synthetic validation — are set out in `docs/index.html`.
